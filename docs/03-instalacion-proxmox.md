# 03-instalacion-proxmox

## Objetivo
Instalar maquina virtual en Virtualbox con sistema Proxmox y configurar adaptadores de red.

## Procedimiento
Descargar ISO de proxmox, crear VM sin el instalador y configurar Virtualizacion anidada y añadir adaptador de red antes de instalar proxmox.

Para la instalacion de proxmox he utilizado el adaptador puente.
